# FitTrack

A modern fitness tracking frontend application built using React and Vite.

## Live Demo
https://fit-track-seven-sigma.vercel.app

## GitHub Repository
https://github.com/TgangadharReddy/FitTrack

## Features
- Modern Landing Page
- Authentication UI
- Dashboard Page
- Responsive Design
- React Router Navigation
- Reusable Components

## Tech Stack
- React
- Vite
- Tailwind CSS
- React Router DOM
- Vercel

## Installation

```bash
git clone https://github.com/TgangadharReddy/FitTrack.git
cd FitTrack
npm install
npm run dev
```

src/
components/
