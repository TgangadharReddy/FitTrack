# FitTrack

Modern fitness tracking web application built using React + Vite.

## Features

- Modern responsive landing page
- Premium UI design
- Animated sections
- Multi-section homepage
- Authentication UI
- Dashboard UI
- Pricing section
- Testimonials
- Contact section
- Mobile responsive design

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

src/
├── components/

├── layouts/
